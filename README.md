# Hunter's Feast — Round 8 / v1.0.0

本版本為前八回整合正式版。

## 功能
- 三階段 SVG 轉盤：地區 → 菜系 → 料理
- 原創哥德獵人風介面
- 用餐時段、預算、辣味、湯類、素食篩選
- 收藏、黑名單與搜尋
- 避免近期重複抽選
- 抽選統計
- 音效、震動、動畫速度設定
- Google Maps 附近餐廳搜尋
- PWA 安裝與離線使用
- v1.0.0 版本標示

## 更新方式
1. 解壓縮 ZIP。
2. 打開解壓後資料夾。
3. 將所有檔案與資料夾上傳到 GitHub Repository 最外層。
4. 覆蓋同名檔案。
5. 等 GitHub Actions 出現綠色勾勾。
6. 用 `你的網址/?v=8` 測試。
7. 確認左下角顯示 `v1.0.0 · Round 8`。

若 iPhone 主畫面仍顯示舊版，刪除舊 App，清除 Safari 該網站資料，再重新加入主畫面。
