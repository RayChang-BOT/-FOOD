# Hunter's Feast — Round 7

版本：v0.7.0

## 本回新增

- 依抽中料理搜尋附近餐廳
- iPhone / Android 定位權限
- Google Maps 搜尋連結
- 不需要 Google Maps API 金鑰
- 定位成功、失敗狀態提示
- 新版 Service Worker 快取
- 左下角版本號 `v0.7.0 · Round 7`

## 使用方式

1. 完成一次三階段狩獵。
2. 按「取得目前位置」並允許定位。
3. 按「搜尋附近餐廳」。
4. 系統會以抽中的料理名稱開啟 Google Maps 搜尋。

也可以不提供位置，直接按「在 Google Maps 開啟」。

## 更新 GitHub Pages

1. 解壓縮 `HuntersFeast-Round7.zip`
2. 打開解壓後的資料夾
3. 將所有檔案與資料夾上傳到 Repository 最外層
4. 覆蓋所有同名檔案
5. 等 GitHub Actions 顯示綠色勾勾
6. 用 `你的網址/?v=7` 測試

若 iPhone 主畫面仍顯示舊版，請刪除舊 App，清除 Safari 該網站資料，再重新加入主畫面。
