# Hunter's Feast — Round 9 / v1.1.0

## 本回新增：菜譜資料庫編輯器

- 在 App 頁面中新增料理
- 修改地區、菜系、料理名稱、價位與標籤
- 設定辣味、湯類與素食屬性
- 刪除料理
- 搜尋資料庫
- 恢復預設資料
- 自訂資料保存在目前瀏覽器的 LocalStorage
- 自訂資料會立即影響轉盤抽選與篩選結果

## 注意

自訂資料只保存在目前裝置與瀏覽器中。
若清除 Safari/Chrome 網站資料，或更換裝置，自訂資料會消失。
